Ondersteuningsniveau-adviseur

Beantwoord een paar vragen over de casus — je krijgt een onderbouwd advies.

Let op: DeepSeek (en de meeste andere AI-providers) staan geen directe aanroepen vanuit de browser toe (CORS-blokkade). Er is daarom altijd een kleine proxy nodig die het verzoek namens jou doorstuurt. Test je lokaal? Gebruik proxy-server.js met Node.js. Host je via GitHub Pages? Gebruik api/chat.js als serverless functie op Vercel — zie DEPLOY-INSTRUCTIES.md voor de stappen. De optie "Claude (standaard)" werkt alleen binnen de Claude-omgeving zelf. Instellingen worden bewust niet lokaal opgeslagen en verdwijnen dus bij een herlaad.
Actief: Claude (ingebouwd)
Voor DeepSeek wordt dit veld automatisch ingevuld; pas aan indien nodig.
Wordt alleen client-side gebruikt en nergens naartoe verstuurd behalve naar het opgegeven endpoint. Deel dit bestand niet met je sleutel erin ingevuld.
