Ondersteuningsniveau-adviseur

Beantwoord een paar vragen over de casus — je krijgt een onderbouwd advies.

Alle providers werken gewoon zodra je dit bestand host via een echt https://-adres (bijv. GitHub Pages). Open je het bestand lokaal via dubbelklik (file://...), dan blokkeert de browser zelf externe API-aanroepen — dat is geen beperking van DeepSeek/Claude, maar van hoe browsers file://-pagina's behandelen. Je sleutel/endpoint/model worden bij "Opslaan" onthouden in de browser van dit apparaat (localStorage), zodat je ze niet telkens opnieuw hoeft in te vullen. Let op: dat betekent ook dat de sleutel in leesbare vorm op dit apparaat blijft staan (zichtbaar via devtools) — gebruik je de pagina op een gedeeld apparaat, klik dan na gebruik op "Terug naar Claude (en opgeslagen sleutel wissen)". De optie "Claude (ingebouwd)" werkt alleen binnen de Claude-omgeving zelf en wordt nooit opgeslagen.
Actief: Claude (ingebouwd)
Voor DeepSeek wordt dit veld automatisch ingevuld; pas aan indien nodig.
Wordt alleen client-side gebruikt en nergens naartoe verstuurd behalve naar het opgegeven endpoint. Deel dit bestand niet met je sleutel erin ingevuld.
